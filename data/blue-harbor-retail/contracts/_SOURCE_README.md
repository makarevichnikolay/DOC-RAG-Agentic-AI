# Source / Provenance

All contract texts in this folder (and `../extra/`) are **synthetic, generated for demo purposes** for the fictional client "Blue Harbor Retail, Inc." in the Contract Intelligence RAG prototype.

- SEC EDGAR retrieval was attempted first, but web access was unavailable in the generation environment (workspace web_fetch timed out), so the fallback synthetic path was used.
- All parties, addresses, names, signatures, and figures are fictional. Any resemblance to real companies or persons is coincidental.
- Documents were drafted in realistic legalese with numbered sections; key facts (terms, renewal notices, rents, caps, governing law) are consistent with `../seed.json`.
