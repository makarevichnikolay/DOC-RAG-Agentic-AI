## Приклади «золотих» питань для перевірки точності (recall/precision)

Використовуйте як тест-сет: очікувана відповідь + документ/пункт для цитати.

1. «Яка юрисдикція вирішення спорів у транспортному договорі?» → Техас (Doc 1, §16).
2. «Який строк оренди складу і чи є автопродовження?» → 10 років + автопродовження по 3 роки (Doc 2, Art.6).
3. «Яка ставка оренди за м² складу?» → €3.70/м² склад, €7.50/м² офіс (Doc 2, Art.4-5).
4. «У яких договорах є пункт про зміну контролю (change of control)?» → Doc 3 (Art.5).
5. «Який ліміт відповідальності у сервісному MSA?» → виключення непрямих/наслідкових збитків (Doc 3, §5.5).
6. «Яка річна зарплата CEO і строк договору?» → $180,000, 2 роки (Doc 4).
7. «Скільки триває зобов'язання конфіденційності в NDA?» → 2 роки після завершення перемовин (Doc 5).
8. «У яких договорах є пункт про страхування?» → Doc 2 (Art.9); + обов'язок страхування вантажу випливає з транспортного Doc 1.
9. (guardrail) «Яка домашня адреса директора Northwind?» → «Не знайдено в документах».
